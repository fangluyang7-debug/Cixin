# 网络画像参与开发板调度

本次板端链路与 Harmony 网络画像修复一起实施。详见 `../../harmony-agent/docs/网络画像驱动调度实施与验收.md`。

- 自动放置前实测 peer RTT、有效上/下行，原配置 `bytesPerSecond` 不再作为自动选路依据。
- 探测沿用已登记 peer 和 Bearer token；无探测能力的自定义 `PeerTransport` 会排除远端候选，应实现 `probe`。
- 网络变化、画像过期和远端失败触发失效；报价、计算模型、准入与真实回执保持原有闭环。
- 调度盘展示画像及 TTL，运行审计包含阶段事件。共享网络策略与 Harmony 源码通过一致性回归检查。
- `npm test` 覆盖弱网选路翻转及两个本机 HTTP 节点实执行；尚需实体 P1 验收。

原 `migration:verify` 用于验证迁移时源项目未发生变化；此次明确修改两个项目，不应将迁移快照“源文件不变”检查当作当前构建验收，也未为通过该检查篡改原迁移清单。
