# Cixin Agent 项目日志

## 2026-09-26：与 Harmony 当前共享链路对齐

- 明确两个项目共用 `harmony-agent/apps/harmony` 的 App、调度 SDK 和 Zeabur 正式购物链路；`cixin-agent` 只保留 P1/多开发板扩展，不复制另一套购物业务。
- 同步 Harmony 最新的云任务调度语义和客户端云遥测类型；远程云任务不再被本机普通资源压力错误降级，临界保护继续生效。
- 同步 TaskGraph/Runtime 的设备画像、网络画像、`cloudRoutes`、分段云反馈、执行状态和端到端估计契约，保留 Cixin 的无电池板卡适配。
- 增加共享 `taskId` 到 Cixin `runId` 的关联和鉴权后的客户端分段遥测回填接口；运行记录不保存业务输入。
- 更新迁移基线到 Harmony 当前提交；未修改 P1、其他开发板、Worker、peer Quote、跨板放置、幂等执行或断联对账逻辑。
- 迁移校验改为固定检查基线提交、Harmony 源目录差异和共享云契约，不再要求当前开发分支永远指向基线提交，因此后续仅修改 Cixin 的提交不会误报失败。
- 验证结果：`npm test` 完成 TypeScript 构建并通过 28 项测试；新增用例覆盖远程云任务不受本地普通资源压力错误降级、共享 taskId/分段遥测关联及鉴权 HTTP 回填。`npm run migration:verify` 通过 23 个源文件和共享云契约检查，`git diff --check` 通过。
- 仍未完成：Zeabur `harmony-agent` 尚未注册 Cixin Fleet 为正式购物执行器，开发板也尚未实现图片识别、商品召回等购物工具；因此当前改动是共享链路和算法对齐，不宣称正式购物任务已经能自动落到 P1。

## 2026-09-24：调度盘真实接入与独立演示入口

用户要求：采用已有调度盘前端设计、显示真实调度信息；App 保持演示角色；提出将本地数据库改为云端数据库以扩展测试方向的方案。

- 在当前 `codex/cixin-multi-device-runtime` 工作区实现，修改范围限于 `cixin-agent`。
- 依据 `harmony-agent/调度盘` 视觉稿新增离线可加载的运行版调度盘，移除原稿的预置硬件数值与模拟波动。
- 新增鉴权监控快照接口，读取真实本地/peer 节点、候选决策、运行记录与执行回执；并发观察请求合并，保留缺失状态和采集时间。
- 将预测值、已确认实测值和未采集值分别展示；静态页面不包含运行数据或令牌；监控投影移除任务结构化 input/output、图 goal 和 inputRef。
- 新增独立 Web 演示 App，支持工具选择、任务 JSON 导入、deadline/远端许可、实际提交与结果回传、单任务取消和未确认回执查询。
- 增加本地控制台启动命令与浏览器回归脚本；27 个 Node 测试条目通过，真实主机的 App → Runtime → 调度盘浏览器联测通过，桌面/手机布局与画布采样检查通过。
- 云数据库方案区分原购物 SQLite 业务库、新 Runtime 本地审计与成本状态，列出 PostgreSQL 迁移、云检索适配器、异步审计同步和对照试验步骤。

实际边界：目前可直接演示真实 CPU 向量检索，不代表图片识别或完整购物 App 已迁入新 Runtime；未连接云数据库，未采集板卡 NPU 利用率与功耗，没有新增 P1 实机性能结论。

文档：[调度盘与演示App接入测试](docs/调度盘与演示App接入测试.md)、[云端数据库改造方案](docs/云端数据库改造方案.md)。
