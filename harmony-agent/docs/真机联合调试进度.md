| 层级 | 要确认的事实 | 当前状态 | 关联问题 |
|---|---|---|---|
| 手机输入与页面事件 | 最终提交内容、是否重复提交、是否切到结果页 | 快捷词提交与结果页已见；输入自动化存在偏差 | OBS-01 |
| 手机配置与用户鉴权 | API 地址、用户登录、token 是否有效 | 地址保存已见；登录成功待验证 | BUG-01 |

| 手机到 Zeabur 网络 | 请求是否发出、HTTP 状态、超时与错误码 | 未确认本次失败请求到达云端 | BUG-01 |
| Zeabur 用户鉴权与任务入口 | 用户身份、taskId、是否创建运行 | 待云端关联日志确认 | BUG-01 |
| 云数据库与商品检索 | 云端实际数据量、索引可用性、命中 | 尚未本轮核验，不能用本地 2496 去重数替代 | 待建问题 |
