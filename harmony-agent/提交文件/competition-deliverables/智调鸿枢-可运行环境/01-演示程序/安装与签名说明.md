# 演示系统安装与签名说明

## 产物

- `entry-default-signed.hap`：HarmonyOS NEXT Phone 演示应用，目标SDK 6.0.2(22)，已通过签名完整性校验。
- `scheduler.har`：端侧AI感知调度中间件，可作为本地HAR依赖集成。

## 安装方式

交付HAP使用 DevEco Managed Profile 生成的 Debug 签名，适合已纳入该调试 Profile 的设备进行近期演示。该证书有效期截至 2026-08-09 23:11:35，不等同于面向任意设备分发的正式 Release 签名。若目标设备不在 Profile 范围内，推荐流程：

1. 使用 DevEco Studio 打开 `../03-源代码/shopping-assistant/apps`。
2. 在工程签名配置中启用调试自动签名，或配置团队正式证书。
3. 选择兼容 HarmonyOS 6.0.2(22) 的 Phone 模拟器/真机。
4. 运行 `entry` 模块，由 DevEco Studio完成签名、安装和启动。

如需生成正式HAP，应在 `apps/build-profile.json5` 中通过 DevEco Studio写入签名配置后重新构建。证书、私钥、Profile和密码不应提交到公共压缩包。

## HAR集成

可将 `scheduler.har` 复制到目标工程并在 `oh-package.json5` 中声明本地依赖；也可直接以源码模块方式引用 `apps/scheduler`。接入应用需注册任务执行器，并为每类端侧AI任务提供能力标识、任务类型、精度偏好和时延预算。

## 能力边界

HAP中的后端字段是调度计划。GPU/NPU/NNRT必须在目标设备上完成执行器初始化和同模型验证后才能视为实际可用；未探测时默认使用CPU。
