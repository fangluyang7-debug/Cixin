# 项目进度跟踪

更新时间：`2026-06-02`

本文档用于记录当前项目的真实落地状态。接口细节以 `docs/16-前端联调接口契约.md` 为准，后续能力以 `docs/17-后续能力TODO总表.md` 为准。

## 1. 当前结论

当前项目已经从“前端 demo + 后端骨架”推进到“云端后端主链路可用，等待继续注入真实商品数据和前端真实接入”的阶段。

已验证的后端主链路：

```text
用户上传鞋图
-> 腾讯云 COS 存图
-> 豆包视觉识图输出鞋类 productProfile
-> 云端返回 normalized bbox 给前端展示
-> 云端按 bbox 裁剪用户图
-> 豆包图片 embedding 生成 query 向量
-> 商品池标签召回 + ANN 召回
-> 候选融合排序
-> CandidateSnapshot / CandidateItem 落库
-> 前端读取 candidates / search-events
```

架构修正：


## 2. 当前产品边界

当前阶段仍聚焦鞋类，不扩展到泛商品。

必须守住的主链路：

```text
拍照/上传鞋图 -> 商品理解 -> 商品池候选 -> 自然语言多轮收敛 -> 商品详情/建议/降级
```

当前不作为主交付范围：

- 抖音小程序
- 历史价格真实链路
- 配送时效真实链路
- 评论/问答洞察
- 非鞋类品类扩展
- 应用商店分发

已进入后端能力范围但仍需前端配合的能力：

- 用户长期画像与待确认记忆
- 用户调整 bbox 后重新生成 query embedding
- 商品池后台管理与异步导入

## 5. 当前可演示路径

### 5.1 前端本地 demo 路径

1. 打开 App 首页。
2. 输入需求，例如：`500以内，只看有货`。
3. 点击 `拍照检索` 或 `从相册选择`。
4. 进入结果页。
5. 查看逐条出现的商品候选。
6. 点击建议卡片或继续输入条件。
7. 点击商品卡查看详情。

### 5.2 后端云端真实路径

1. 上传样例鞋图到 `POST /api/v1/assets/images`。
2. 使用 `assetId` 调 `POST /api/v1/sessions`。
3. 读取返回的 `productProfile` 和 `queryImagePreprocess`。
4. 调 `GET /api/v1/sessions/:sessionId/candidates` 查看候选。
5. 调 `GET /api/v1/sessions/:sessionId/search-events` 查看进度事件回放。
6. 可选：调 `POST /api/v1/sessions/:sessionId/subject-selection` 验证用户调整 bbox 后刷新结果。

自动验证命令：

```powershell
npm run api:smoke:cloud -- `
```
