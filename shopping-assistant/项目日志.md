# 项目日志

更新时间：2026-09-06

本文只记录当前仓库已经完成的事实、尚未补齐的资源，以及暂时不能伪造的能力。

## 当前进展

- 项目已按“`Shopping Assistant` 作为测试应用，`Agentic Runtime` 作为通用底座”的方向整理。
- 已补充 `docs/06-Agentic-AI与应用解耦架构设计.md`，并同步维护 `docs/runtime-resource-gaps.md`。
- Runtime 协议、工具注册、任务图校验、资源调度、阻断逻辑、平台适配分层和运行快照已落到代码里。
- 购物业务已收敛为业务插件，不再作为 Scheduler 的硬编码边界。
- 当前代码会优先返回真实可观测结果；没有真实证据时，任务进入 `blocked`，不会写死 CPU/GPU/NPU 链条。

## 当前缺少的东西

### 外部资源

- 云端数据库托管平台、实例地址、库名、账号、密码和 TLS 配置。
- 云端对象存储、区域、Endpoint、Bucket 和访问密钥。
- 云端 API 网关或服务部署地址，以及域名、证书和网络配置。
- Agent Planner 对应的大模型平台、模型名称、API 地址、密钥、配额和超时策略。
- 视觉模型、聊天模型、Embedding 模型的真实供应商、模型名、密钥和维度信息。
- 淘宝、抖音电商、拼多多、得物、京东等授权 API、调用范围和限流凭据。
- 可验证的商品池来源、更新时间和失效策略。

### 真机与运行时

- HarmonyOS 真机或开发板、系统版本、连接方式和 SDK。
- CIX P1 真机或开发板、系统版本、连接方式和 SDK。
- CPU/GPU/NPU 的真实设备信息和统一适配器实现。
- 目标模型文件、算子支持矩阵、INT8/FP16 能力和 CPU fallback 结果。
- 模型加载、推理、取消、检查点和结果回传接口。
- GPU/NPU 利用率、温度、电量、磁盘和网络监测接口。

### 运行数据

- 真实性能样本库，至少要包含 P50/P95 延迟、峰值内存、能耗、温升、质量、失败率和 fallback 次数。
- 持久化 Telemetry 和跨进程性能学习结果。
- 真实 Agent Planner 的任务拆解与重规划闭环。
- 执行器调用层、阶段级 checkpoint、取消、恢复、降级重试和迁移能力。

## 现阶段结论

在上述资源和能力补齐前，项目只能作为 Runtime 协议、调度阻断和测试入口继续推进，不能把缺口伪装成已完成能力。
